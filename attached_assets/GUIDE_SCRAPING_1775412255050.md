# Guide — Scraping Unibet & Betclic (cotes buteurs/passeurs)

Ce guide est destiné à un agent Claude Code.
Il contient tout ce qu'il faut pour mettre en place le scraping depuis zéro.

---

## Vue d'ensemble

Le script `scrape_odds.py` récupère les **cotes pré-match** (buteur anytime,
1er buteur, passeur décisif) depuis Unibet et Betclic, sans Playwright, sans
LLM, sans base de données.

| Bookmaker | Méthode technique | Authentification |
|-----------|-------------------|-----------------|
| Unibet    | API REST JSON (plateforme LVS, post-fusion PSEL mars 2026) | Token anonyme via `/lvs-api/acc/token` |
| Betclic   | gRPC-web + HTML SSR (Angular ng-state) | Aucune |

**Seule dépendance :** `httpx`

## 5. Fonctionnement interne

### Unibet (API LVS)

Flux en 3 étapes, tout en HTTP/JSON :

```
1. GET /lvs-api/acc/token
   → reçoit { "hsToken": "xxx" }
   → utilisé comme header X-LVS-HSToken pour toutes les requêtes suivantes

2. GET /lvs-api/next/50/p{node_id}?lineId=1&originId=3&...
   → liste les événements à venir pour une ligue
   → node_id par ligue (voir tableau ci-dessous)
   → extrait : event_id (clé "eXXX"), home ("a"), away ("b"), kickoff ("start")

3. GET /lvs-api/ff/e{event_id}?lineId=1&originId=3&...
   → retourne TOUS les marchés d'un match (dict plat)
   → marchés ciblés par markettypeId :
       31        → "goalscorer" (buteur anytime, priorité haute)
       4         → "goalscorer" (1er buteur, priorité basse — dédupliqué)
       100002524 → "assist" (passeur décisif)
   → les outcomes (clés "oXXX") ont : desc (nom joueur), price (cote)
   → format de cote : virgule française "3,05" → convertir en float 3.05
```

**Node IDs par ligue (à jour en mars 2026) :**

| Ligue | node_id |
|-------|---------|
| ligue_1 | 58531576 |
| premier_league | 58532401 |
| bundesliga | 58529612 |
| la_liga | 58532237 |
| serie_a | 58529754 |
| champions_league | 58532497 |

> Si une ligue retourne 0 événements, vérifier que le node_id est toujours valide
> en inspectant le réseau sur www.unibet.fr (Network > XHR > filtre "lvs-api").

**Format du timestamp kickoff LVS :** `YYMMDDHHMM` (10 chiffres)
- Exemple : `"2604051930"` → 2026-04-05 19:30 UTC

### Betclic (gRPC-web)

Flux en 2 étapes :

```
1. GET https://www.betclic.fr/football-s1/{slug}/
   → page HTML Angular
   → extraire le tag <script id="ng-state" type="application/json">
   → dans ce JSON, accéder à la clé "grpc:4011162472" > "response" > "payload"
   → payload contient la liste des matchs : matchId, matchDateUtc, contestants[]

2. POST https://offering.begmedia.com/web/offering.access.api
         /offering.access.api.MatchService/GetMatchWithNotification
   → corps : message protobuf encapsulé dans un frame gRPC-web
   → réponse : stream gRPC-web chunked → décoder le premier data frame
   → parser le protobuf à la main (voir structure ci-dessous)
```

**Corps de la requête gRPC-web (protobuf) :**
```
field 1 (int64)  = match_id
field 2 (string) = "fr"

Encodage gRPC-web : 0x00 + uint32_be(len_proto) + proto_bytes
```

**Headers obligatoires pour le POST gRPC :**
```
content-type: application/grpc-web+proto
x-grpc-web: 1
x-bg-ref-platform: DESKTOP
x-bg-regulation: FR
x-bg-ref-brand: BETCLIC
x-bg-ref-regulator-zone: FR
origin: https://www.betclic.fr
```

**Structure protobuf de la réponse :**
```
root.f1.f1.f11.f3[]  = liste des marchés
  market.f2  = nom du marché (bytes UTF-8)
  market.f9  = état (3 = suspendu → ignorer)
  market.f11[] = groupes de sélections
    group.f2[] = sélections
      sel.f10 ou sel.f11 = nom du joueur (bytes UTF-8)
      sel.f12 = cote (8 bytes, IEEE 754 double little-endian)
```

**Classification des marchés par nom :**
- `"buteur (tps r..."`, `"buteur anytime"`, `"scorer anytime"` → `goalscorer`
- `"passeur"`, `"joueur décisif"` → `assist`

**Slugs et competition IDs Betclic :**

| Ligue | slug | competition_id |
|-------|------|----------------|
| ligue_1 | ligue-1-s4 | 4 |
| ligue_2 | ligue-2-s19 | 19 |
| premier_league | premier-league-s3 | 3 |
| la_liga | laliga-s7 | 7 |
| bundesliga | bundesliga-s5 | 5 |
| serie_a | serie-a-s6 | 6 |
| champions_league | champions-league-s15 | 8 |
| europa_league | ligue-europa-s3453 | 3453 |
| coupe_de_france | coupe-de-france-s36 | 36 |

## 6. Intégration dans un projet

### Lire le JSON depuis un autre script Python

```python
import json, subprocess

result = subprocess.run(
    ["python", "scrape_odds.py", "--output", "json"],
    capture_output=True, text=True
)
matches = json.loads(result.stdout)

for match in matches:
    print(match["home_team"], "vs", match["away_team"])
    for sel in match["selections"]:
        if sel["market_type"] == "goalscorer":
            print(f"  {sel['player_name']}: {sel['odds']}")
```

### Importer les fonctions directement

```python
import asyncio
from scrape_odds import scrape_unibet, scrape_betclic

async def main():
    matches = await scrape_unibet(["ligue_1", "premier_league"])
    matches += await scrape_betclic(["ligue_1", "champions_league"])
    for m in matches:
        print(m.home_team, "vs", m.away_team, f"({m.bookmaker})")
        for s in m.selections:
            print(f"  [{s.market_type}] {s.player_name}: {s.odds}")

asyncio.run(main())
```

### Cron — scrape toutes les heures

```bash
# crontab -e
0 * * * * cd /chemin/vers/projet && python scrape_odds.py --output json >> /var/log/odds.jsonl 2>&1
```

> Chaque exécution ajoute une ligne JSON par match. Utiliser `jq` pour filtrer :
> `cat /var/log/odds.jsonl | jq 'select(.bookmaker == "betclic")'`

### Stocker dans SQLite (exemple minimal)

```python
import asyncio, json, sqlite3
from scrape_odds import scrape_unibet, scrape_betclic

def init_db(path="odds.db"):
    con = sqlite3.connect(path)
    con.execute("""
        CREATE TABLE IF NOT EXISTS selections (
            scraped_at  TEXT,
            bookmaker   TEXT,
            league      TEXT,
            home_team   TEXT,
            away_team   TEXT,
            kickoff_utc TEXT,
            market_type TEXT,
            player_name TEXT,
            odds        REAL
        )
    """)
    con.commit()
    return con

async def main():
    from datetime import datetime, UTC
    con = init_db()
    now = datetime.now(UTC).isoformat()

    matches = await scrape_unibet(["ligue_1"])
    matches += await scrape_betclic(["ligue_1"])

    rows = [
        (now, m.bookmaker, m.league, m.home_team, m.away_team,
         m.kickoff_utc.isoformat() if m.kickoff_utc else None,
         s.market_type, s.player_name, s.odds)
        for m in matches for s in m.selections
    ]
    con.executemany("INSERT INTO selections VALUES (?,?,?,?,?,?,?,?,?)", rows)
    con.commit()
    print(f"Inséré {len(rows)} sélections")

asyncio.run(main())
```

## 7. Dépannage

### Unibet retourne 0 matchs

**Cause probable :** le node_id de la ligue a changé (Unibet recrée les nodes
à chaque saison ou après une migration de plateforme).

**Comment trouver le bon node_id :**
1. Ouvrir www.unibet.fr dans Chrome
2. Aller sur la page de la ligue (ex : Ligue 1)
3. Ouvrir les DevTools → Réseau → filtre `lvs-api/next`
4. L'URL aura la forme `/lvs-api/next/50/p58531576` — récupérer le nombre après `p`

### Betclic retourne 0 matchs

**Cause 1 : IP non-française**
Betclic redirige ou retourne une page vide pour les IPs hors UE.
Solution : utiliser un proxy ou VPN avec IP française.

```python
# Avec proxy HTTP dans scrape_odds.py
httpx.AsyncClient(proxies={"all://": "http://proxy-fr:8080"})
```

**Cause 2 : clé ng-state changée**
La clé `"grpc:4011162472"` est un hash Angular qui peut changer lors d'un
déploiement frontend.

**Comment trouver la nouvelle clé :**
```python
import httpx, json, re

r = httpx.get("https://www.betclic.fr/football-s1/ligue-1-s4/")
m = re.search(r'<script[^>]*id="ng-state"[^>]*>(.*?)</script>', r.text, re.DOTALL)
if m:
    data = json.loads(m.group(1))
    # Chercher la clé qui contient "matches"
    for key, val in data.items():
        if isinstance(val, dict) and "matches" in str(val)[:200]:
            print("Nouvelle clé :", key)
```

Mettre à jour la ligne suivante dans le script :
```python
payload = ng.get("grpc:NOUVELLE_CLE", {}).get("response", {}).get("payload", {})
```

**Cause 3 : structure protobuf changée**
Si Betclic met à jour son API gRPC, la hiérarchie `f1.f1.f11.f3` peut changer.
Inspecter la réponse brute avec `--verbose` et retracer la structure.

### Cotes suspendues / manquantes

Normal. Les cotes sont suspendues quand le marché est fermé (match proche ou
déjà en cours). Le script ignore silencieusement les sélections à `null`.

### Rate limiting / ban IP

Les sleeps de 0.3s entre requêtes sont intentionnels. Ne pas les supprimer.
En cas de ban temporaire (HTTP 429 ou 403), attendre 10-15 minutes.

## 8. Étendre le scraper

### Ajouter une ligue Unibet

1. Sur www.unibet.fr, naviguer vers la ligue
2. Récupérer le node_id (voir section Dépannage)
3. Ajouter dans `_UNIBET_NODE_IDS` :
   ```python
   "eredivisie": 58530000,  # exemple
   ```

### Ajouter une ligue Betclic

1. Sur www.betclic.fr, récupérer l'URL de la compétition :
   ex. `/football-s1/eredivisie-s42/` → slug = `eredivisie-s42`
2. Dans le ng-state, le `competition.id` est le numéro après `-s` → `42`
3. Ajouter dans `BETCLIC_LEAGUES` :
   ```python
   "eredivisie": ("eredivisie-s42", "42"),
   ```

### Ajouter un marché Unibet

Identifier le `markettypeId` via les DevTools (réponse `/lvs-api/ff/eXXX`),
puis l'ajouter dans `_UNIBET_MARKET_TYPES` avec le nom canonique voulu.

### Ajouter un bookmaker

Créer une nouvelle fonction `scrape_BOOKMAKER(leagues)` qui retourne
`list[MatchOdds]`, en réutilisant les dataclasses `MatchOdds` et
`SelectionOdds` déjà présentes dans le script. L'intégrer dans `_main()`.

## 9. Notes légales

Ce script interroge des APIs publiques non authentifiées.
Vérifier les CGU du bookmaker avant usage commercial ou automatisé intensif.
Les APIs privées (gRPC Betclic, LVS Unibet) peuvent changer sans préavis.
